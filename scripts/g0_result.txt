## §2 Mechanisms (对照 original locations)

- `Cargo.toml`: `[features] unsafe-ffi = []` (default OFF).
- `src/modules/modselect.rs` — two paths, shared pre-checks unchanged
  (non-list → TypeError; negative/NaN timeout → OSError(22)):
  - ON: hand-written `extern "C" { fn select(...); fn
    __errno_location(); }` (no libc crate); `FdSet = [u64; 16]`
    (c_long is 8 bytes on both x86_64 and aarch64 — same as
    `modselect.zig`'s `bits_per_long`); `Timeval { tv_sec: i64,
    tv_usec: i64 }`; `timeval_from_secs` (trunc + clamp [0, 999999],
    saturating `as`); `select_real` follows `modselect.zig::py_select`:
    populate skips fd < 0 / >= 1024, `nfds` = max fd + 1, all lists
    empty → nfds 0 + all three sets NULL (`select(0, NULL, NULL,
    NULL, tv)` just sleeps), `n < 0` → read `*__errno_location()`
    immediately, raise OSError, NO EINTR retry (the Zig doesn't
    retry either); results keep input order + the original fd
    objects (`filterReady` appends `list.items[i]`).
  - OFF: existing implementation untouched (sleep + NotImplementedError).
  - Feature-only helpers/imports/tests are `#[cfg(feature =
    "unsafe-ffi")]`-gated so the default build has 0 warnings and
    exactly 1700 lib tests (found by the forced-rebuild warning
    check: 9 dead-code warnings before gating).
- `src/modules/modd4_tests.rs`: `d4_select_nonempty_not_implemented`
  now `#[cfg(not(feature = "unsafe-ffi"))]`; added 7 feature-gated
  tests (`g0_select_devnull_readable`,
  `g0_select_listener_readable_then_drained`,
  `g0_select_write_ready`, `g0_select_ebadf`,
  `g0_select_fd_over_1024_skipped`, `g0_select_dup_fd`,
  `g0_select_xlist_not_ready`).
- `.cargo/config.toml` (NEW) + `scripts/zig-cc-aarch64.sh` (NEW):
  `[target.aarch64-unknown-linux-gnu] linker =
  "scripts/zig-cc-aarch64.sh"`; the script resolves `zig` from PATH
  (fallback `/home/hatch/zig-x86_64-linux-0.16.0/zig`), calls
  `zig cc -target aarch64-linux-gnu`, strips
  `-Wl,--fix-cortex-a53-*` (GNU-ld only; lld handles the erratum)
  and `-Wl,-O1` (a GNU-ld hint that lld only warns about — the
  arm64 build initially showed 5 warning lines, all that one
  linker-message warning; after the strip it is 0).
- `README.md`: status table now 202/202 with the feature, 200/202
  default; divergence list updated (ceiling claim removed, arm64
  cross-compile verified / runtime unverified noted).

## §3 Probes (release binary, `~/workspace/g0_probe/select_probe.py`;
REF = `~/workspace/petitpy-orig/zig-out/bin/petitpy`, RUST = worktree
`target/release/petitpy-rs` with the feature on; all byte-compare
stdout+stderr+rc unless noted)

- `int_case_devnull`: `select([fd_of_/dev/null], [], [], 0)` → True.
  IDENTICAL.
- `int_case_listener`: fresh AF_UNIX listener, `select([fileno],
  [], [], 0)` → empty. IDENTICAL.
- `devnull_write_ready`: `select([], [w_of_/dev/null], [], 0)` →
  1 ready. IDENTICAL.
- `ebadf`: closed fd into select → `OSError: [Errno 9] EBADF`,
  traceback byte-identical, rc=1 both. IDENTICAL.
- `fd_over_1024`: fd 2000 into select → `[] [] []`, rc=0.
  IDENTICAL (silent skip, as the Zig's `populateSet`).
- `dup_fd`: same fd twice in rlist → result count 2.
  IDENTICAL (reference keeps duplicates).
- `xlist_not_ready`: `/dev/null` O_RDONLY fd in xlist, timeout 0 →
  0 ready. IDENTICAL.
- `neg_fd_skipped`: fd −1 into select → `[] [] []`, rc=0.
  IDENTICAL.
- `listener_readable`: Unix listener + CPython client connects while
  the binary is blocked in `select(..., 5)` → `ready\n1\n0\n`,
  rc=0 both. IDENTICAL. (First run showed a DIFF: the reference
  buffers stdout when piped, so a `readline()` "ready" sync only
  returns after the process exits — the client then connected after
  select had already timed out. Fixed by sleeping 1 s before
  connecting; a direct manual run with the same timing gives 1 on
  both binaries. See §4 for the buffering finding.)
- `timeout_0.2`: timed INSIDE the script (`time.time()` around the
  call): REF 0.200 s, RUST 0.200 s. OK. (First version timed the
  whole subprocess including startup: REF 0.310 s — the 27 MB Debug
  reference takes ~0.1 s to start; the script-internal timing is
  the honest measure.)

## §4 Left-open

- **arm64 runtime unverified.** `apt-get install -y qemu-user`
  succeeded (qemu-aarch64 1:8.2.2 present), and a qemu run was
  attempted, but this VM has no aarch64 glibc sysroot — no
  `/lib/ld-linux-aarch64.so.1` anywhere (Zig's bundled glibc dir
  holds headers/stubs only) — so `qemu-aarch64` fails with
  "Could not open '/lib/ld-linux-aarch64.so.1'". Cross-compile
  passes; runtime needs a real arm64 machine or a sysroot.
- **Huge/infinite timeout**: the original aborts (`@intFromFloat`
  panic); Rust saturates `tv_sec` to `i64::MAX` (feature path) or
  sleeps `Duration::MAX` (default path) — the pre-G0 divergence,
  kept as-is per the brief.
- **`os.pipe` does not exist on either binary**: the first probe
  draft used `os.pipe()`; both REF and Rust raise AttributeError
  (`hasattr(os, 'pipe')` is False on the reference too — the D2 os
  module never exposed it). Not a select gap; probes and tests were
  rewritten to use Unix listeners / `/dev/null` instead.
- **Reference buffers stdout when piped** (probed 2026-11-19 while
  fixing the listener probe): with `print('hello'); time.sleep(2)`,
  the first line arrives after 2.11 s on the reference, 0.00 s on
  Rust (write-through). Pre-existing print-flushing divergence,
  unrelated to select, out of G0 scope; recorded here because it
  bit the probe sync.
- No other divergences found in this lane. Nothing else was touched.
