3. The 9 dispatch tests (all in `tests_dispatch.rs`)
-----------------------------------------------------
- `dispatch_int_maybe_small_int_fast_path`: INT_MAYBE on a small
  int returns it via C6's `call_unary` fast path (no slot consulted).
- `dispatch_int_maybe_heap_int_via_slot`: INT_MAYBE on a heap
  2**70 reaches the int slot and returns the same value.
- `dispatch_int_unary_via_slot`: Negative/Bool/Hash on small ints
  and Negative on heap -(2**70) through `call_unary`.
- `dispatch_int_binary_add_and_compare`: Add(3,4)=7, Add(2**70,1),
  Less, Equal through `call_binary`.
- `dispatch_bool_ops_via_slot`: Bool unary on True, Add(True,True)=2,
  Multiply(True,3)=3, Less(True,False)=false through the bool slot.
- `dispatch_nothandled_is_not_implemented`: LEN on int, float rhs
  in Add, LEN on bool — all `SlotOutcome::NotImplemented`.
- `dispatch_raise_signals_pyraise`: adapter converts a rich raise
  (FloorDivide by zero) to `Err(PyError::PyRaise)`, NotHandled the
  same way, a handled op to `Ok`; `call_binary` maps the raise to
  `NotImplemented` (see §4).
- `dispatch_print_int_and_bool`: `obj_print_helper` writes "42"
  (Str and Repr — kind ignored), "1180591620717411303424" for
  2**70, "True"/"False"; a plain float type with no print slot
  falls back to "<float>".
- `dispatch_cell_slots_stay_none`: `call_unary`/`call_binary` on a
  cell-typed value find no slot -> `NotImplemented`.

4. Conventions recorded (not bugs — do not "fix" later)
-------------------------------------------------------
- Raise data is dropped at the slot boundary: the adapter maps
  both `NotHandled` and a rich `PrimError` to `Err(PyError::PyRaise)`,
  and C6's `call_unary`/`call_binary` map that to
  `SlotOutcome::NotImplemented`. The control flow is the original's;
  the raise data is not yet preserved. C13 adds `pending_exc` to
  the VM and resolves it for all lanes at once (C6's
  `objcore_result.txt` §3b/§3c, same convention).
- `PrimError` stays int-specific and is NOT merged into C6's
  `ObjError`; both follow the same (exc_type, message, to_pyerror)
  shape in their own domains.
