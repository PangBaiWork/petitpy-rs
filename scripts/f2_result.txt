§2 Mechanisms
--------------
1. io_error_name full table (src/entry/mod.rs:34): was 7 errnos
   with an OS-message fallback; now the union of the two errno
   switches behind the reference's single `readFileAlloc[Options]`
   call (main.zig:179/396, main_vm.zig:220) — `dirOpenFile`
   (Zig 0.16.0 lib/std/Io/Dispatch.zig ~line 2598) for the open
   half, `fileReadStreaming` (~line 1766, EIO->InputOutput) for
   the read half. 22 rows + fallback `Unexpected`
   (posix.unexpectedErrno, lib/std/posix.zig:1669, returns
   error.Unexpected). Two E1 mappings were WRONG and are fixed
   (see §3): 13 EACCES -> AccessDenied (not PermissionDenied),
   22 EINVAL -> BadPathName (not InvalidArgument — that name is
   not in the Zig switch at all). New probed rows: 24 EMFILE ->
   ProcessFdQuotaExceeded, 6 ENXIO -> NoDevice. Serves both CLIs
   (same fn; petitpy-vm prints `error: {name}` first line).
2. fgets_chunk (src/support/readline.rs): two real C-fgets
   semantic gaps fixed, nothing else touched (4096 param kept):
   (a) loop `fill_buf` until \n / limit / EOF / error — a single
   short pipe read used to end the chunk early, so a 4000-byte
   REPL line arriving in pieces was exec'd as two lines
   (prompt counts 9 vs reference 7); (b) truncate the returned
   chunk at the first NUL byte (the Zig side measures the line
   with `strlen`) while still consuming through the \n/limit
   exactly as C fgets does — a NUL-first line reads as length 0,
   which the REPL treats as EOF, like the original. A read error
   still discards the partial line (fgets NULL semantics).
   `readline` (input()) inherits both fixes through the same
   helper. New tests in src/support/tests.rs: ShortFill BufRead
   (≤7-byte fills), f2_fgets_loops_over_short_fills,
   f2_repl_line_truncates_at_nul; io_error_name pinned by a
   table-driven test in src/entry/mod.rs.
3. README.md (NEW, repo root): what the project is, status table
   with final numbers, build, both CLIs, embedding API, test
   commands, layout, and the honest divergences list compiled
   from F1/F3/F5a/F5b/F6 §4 + E1/E2 leftovers. docs/任务书.md
