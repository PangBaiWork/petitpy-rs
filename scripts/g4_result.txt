H1 — float() runs __float__ (commit 6131427):
- NEW call_float_ctx in src/runtime/builtin_str.rs: intercepts the float TYPE object by GcRef identity in
  src/runtime/vm_call_intercept.rs (before the bool_ branch — the str/bool shape, NOT the hash FunBuiltin
  branch: float is a type object, vm_builtins_bind.rs:262). Runs __float__ through try_instance_unary_op
  (UnaryOp::FloatMaybe) with the real hook; the result must BE a float (mp_obj_get_float_maybe,
  obj.zig:662-690) and is re-wrapped with new_float; a non-float return / no dunder / raising __float__
  falls through to call_type_ctx on ctx.types.float, which raises exactly TypeError: can't convert to
  float (the raise is drained by try_instance_unary_op/drain_hook_raise, no stale pending raise).
  Refined probes (REF only): __float__ returning 5 / "x" / None -> TypeError; __float__ raising
  ValueError("boom") -> TypeError (the raise is SWALLOWED by the conversion — the unary op returns NULL);
  float subclass without __float__ -> native value; float(1, 2) -> arg mismatch; float([1]) -> TypeError.
- Tests: 4 new in src/runtime/vm_tests_g4.rs (dunder runs, non-float return is TypeError, raising dunder
  is swallowed to TypeError, float subclass without dunder still native).
