## §4 遗留 / 未修原因

- `str()` / `repr()` 构造仍走 `String` sink（`ByteSink` 默认
  lossy）：`repr('…\xff…')` 得到的 str 值仍含 U+FFFD，`print()`
  输出已是字节精确。修它需把 `str`/`repr` 内置的渲染也改成
  `ByteBuf`，属同一机制的延伸，未在 G2 范围内做。
- petitpy-vm 缺失文件时 REF 打印 Zig 栈跟踪，Rust 只印首行
  `error: FileNotFound`——地址噪声，不可复现，不修（triage 已定）。
- `ppy_exec` 非 UTF-8 文件名仍 lossy（F1 在 `read_config` 层的
  `from_utf8_lossy`；P7a 修的是 CLI argv 路径，不是 API 路径）。
- 一次瞬态：`cargo test` 曾报 `panic strategy abort vs unwind`
  不兼容（增量指纹混合），重跑即好，未复现；非代码问题。
- 本 lane 基线 4712f27；合并时需 rebase 到当前 master（G0 已合
  并，见 parent 侧；G0 的 `modselect.rs` / feature 与本 lane 文件
  无交集）。
