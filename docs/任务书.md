## 三、剩余工作总表（约 40,000 行 Zig + 2,040 行 vendor C）

### 3.1 关键设计决策（主 agent 冻结，见 `docs/value-obj-design.md`）

原项目的值模型是 C 互操作层：`Obj = usize`（REPR_A 标签指针：小整数
`(n<<1)|1`、62 位窗口、立即数 `OBJ_NONE=6 / OBJ_FALSE=14 / OBJ_TRUE=30`），
`mp_mirrors.zig`（1,082 行）用 `extern struct` 镜像 C 结构体，
`obj.zig` 用 `@cImport` + `extern fn` 调 vendor C。

**Rust 里没有 vendor C 可供镜像，因此不移植 `mp_mirrors.zig` 本身，
而是按其语义定义原生 Rust 值模型**：`Value` 枚举（内联立即数 +
GC arena 句柄）、`Obj` 枚举（全部对象种类）、`GcArena`（mark-sweep，
不移动对象）、显式 GC 根（Rust 栈不可保守扫描，VM 的值栈、全局量、
mpstate 必须显式登记为根）。行为（isinstance、hash、相等、repr、
异常语义）必须与原版一致；内部表示（指针标签、结构体布局）不要求
与 C 相同，`.mpy` 格式不编码对象布局。

- **C0（主 agent 亲自做，最先）**：Value/Obj 接口设计 + 骨架
  （`src/objects/value.rs` + `src/memory/gc.rs` 骨架 + 设计文档）。
  冻结后 Phase C/D 的 lane 才能开工。C0 不等任何 lane。
- **qstr 统一**：编译器 qstr（A1）与运行时 qstr（C1）共用一张表
  （已验证同号）；运行时 qstr 的注释声称 N_MAIN=216 是 stale 的，
  以实测 385/613 为准。

- H-socket（brief `scripts/h_socket_brief.md`）：单文件跨平台 `modsocket.rs`（删 `modsocket_win.rs` stub）；INET 走 `std::net`（TCP/UDP、connect、sendto/recvfrom、timeout、getaddrinfo、makefile），AF_UNIX 走 `std::os::unix::net`（`cfg(unix)`；Windows 上 AF_UNIX 统一 `NotImplementedError`，std 没有 API）；getsockopt/setsockopt 用影子状态 + std 能真正落地的子集（set_nodelay/set_broadcast/set_ttl/超时）；`fromfd` 砍掉（safe Rust 做不到 `FromRawFd`）；fd 从构造起用真 socket 占位（删 `/dev/null` 占位），bind/connect 后 fd 会变（纯 std 没有未绑定 TCP socket 的构造器，文档注明）；`bind("")` AF_UNIX 走 std 行为（unnamed，非原版 abstract socket）；listener 上 send/sendall 改报 `OSError(ENOTCONN 107)`（合 CPython，顺手修 G6b §4 遗留）；`SO_PEERCRED` 全平台统一 `OSError(ENOPROTOOPT)`（std 无稳定 API）；gethostname/gethostbyname 不做（std 无 API）。

- H-subprocess（brief `scripts/h_subprocess_brief.md`）：保持 `_spawn_and_wait` 原语 + frozen `subprocess.py` 不变；删 U5（SIGTERM+1s grace）与 U8（pre_exec dup2）两条 feature 路径——超时 kill 一律 `Child::kill`（SIGKILL，returncode -9，无 grace，全平台一致）；fd 流模式改走 `try_clone_to_owned` + `Stdio::from(File)`（dup 共享 offset，比现默认的 `/proc` 重开更接近原版 dup2）；spawn 失败仍映 127；argv/env 校验保持。修正（主 agent 2026-11-20 ~04:43，lane §4）：`fd_stdio` 需 1 个 std-only unsafe 块（`BorrowedFd::borrow_raw` 是 unsafe fn；BuiltinFn 拿不到 VmState/fd 表，拦截版需碰 H-socket 的 modsocket.rs）——接受，验收改为“仅允许这 1 个 unsafe 块（std-only，带不变量注释），无 FFI、无 C”；Windows fd 模式除 0/1/2 外一律 EBADF（FunBuiltin 看不到 state.os_fds；此前 `/proc` 路径在 Windows 上也从未工作过，非回归）。

### 3.8 Socket FFI 完整实现（2026-11-20 ~17:20，PangBai 指令“完整实现socket使用ffi，当开启标志时实现”）
